# 접근성: 사람이 확인할 것 (MAS-D, 2026-10-19, main f535aa1)

자동 검사(check-logic의 접근성 53줄, AX 트리 감사: 화면 11개에서 이름 없는 컨트롤 0)를 통과했습니다. 아래는
VoiceOver와 Accessibility Inspector로 사람이 순서대로 확인할 항목입니다.

1. VoiceOver를 켜고(⌘F5) 메뉴바 Mwoyeo를 엽니다. Pause all, 번역 언어(출발/도착), Add Lens, Settings, Quit의
   이름이 읽히는지 확인합니다. 렌즈 행에서 VO+⌘Space로 Remove Lens 동작이 있는지 봅니다.
2. Add Lens(⌃⌥L) 뒤 화살표 키를 누릅니다. 렌즈가 화면 가운데에 나타나는지, 화살표로 옮기고 ⇧+화살표로 크기를 바꾸며
   위치가 읽히는지 봅니다. 화면 위쪽 안내 줄 아래에 키 안내가 하나 더 뜨는지도 봅니다. Return 뒤 "렌즈를 놓았습니다"가
   읽히고 원래 앱이 키 입력을 다시 받는지, Esc도 그런지 확인합니다.
3. VO+F2나 Inspector로 놓인 렌즈에 닿는지 봅니다. 아직 확인하지 못한 가장 큰 항목입니다. 창 제목이 "번역 렌즈, 이름"인지,
   값이 "번역됨: …"인지, VO+⇧↓로 번역문이 읽히는지 봅니다.
4. 렌즈 동작 네 가지(원문/번역 보기, 모두 일시정지, 렌즈 제거, 렌즈 메뉴 열기)를 실행해 봅니다. "복사됨" 같은 알림이
   포커스를 옮기지 않고 읽히는지 봅니다.
5. 설정 다섯 탭에서 단축키 행이 "Add Lens, ⌃⌥L"처럼 읽히는지, 폴더·설정 파일 버튼이 서로 구분되는지 봅니다.
6. 온보딩에서 데모가 한 번만 읽히고, 허용 / 바로 해 보기 / 시작하기에 닿는지 봅니다.
7. 손쉬운 사용 › 디스플레이 › 동작 줄이기를 켭니다. 메뉴의 빈 상태, 온보딩 데모, 읽는 중인 렌즈의 빛이 멈추는지 봅니다.
   창을 연 채 껐다 켜도 바로 반영되는지 봅니다. 동작 줄이기에서는 바뀐 모습을 비전 판정으로 보지 못했으니 눈으로
   확인합니다.
8. Inspector의 Audit을 메뉴 패널, 설정, 렌즈 창에 돌립니다. 대비 경고를 특히 봅니다. 렌즈 pill 글자(알파 0.6)의
   대비는 아직 재지 않았습니다.
9. (선택) Voice Control로 "Show numbers"를 말해 메뉴와 설정을 확인하고, 렌즈 놓기 화면에서 "Press right arrow"를
   해 봅니다.

## App Store Accessibility Nutrition Label (v1)

- **동작 줄이기(Reduced Motion):** 주장할 수 있습니다. 자동 검사로 확인했고, 위 7번만 남았습니다.
- **VoiceOver:** 아직 주장하지 않습니다. 놓인 렌즈를 키보드로 옮기거나 크기를 바꿀 수 없고(포인터 전용), 위 3번이
  확인 전입니다. "모든 일반 작업을 그 기능으로 할 수 있어야 한다"는 조건을 아직 못 채웁니다.
- **Voice Control, 충분한 대비(Sufficient Contrast):** 확인 전이라 주장하지 않습니다.
