# 日本語 (ja)

Source: the English section of ../metadata.md, in です/ます. UI terms from App/Resources/Localizable.xcstrings; Screen Recording and Reduce Motion as in Japanese System Settings.

**Name** (19): `Mwoyeo – リアルタイム画面翻訳`

**Subtitle** (15): `切り替わる画面を、その場で翻訳`

**Promotional text** (96):
画面が変わると、訳もすぐ変わります。新しいチャット、切り替わる字幕、スクロールするページをレンズが読み続け、同じ場所に同じ大きさと色で書き直します。初期設定ではすべてMacの中で処理されます。

**Keywords**: `OCR,ゲーム,字幕,チャット,論文,通訳,韓国語,中国語,英語,レンズ,ライブ`

**Description**:
画面の外国語の文字を、その場でリアルタイムに翻訳。

チャットの新着メッセージ、切り替わる字幕、スクロールするページ。訳文は画面の変化についていきます。

ポップアップも字幕バーもありません。Mwoyeoはレンズの下の文字を読み取り、画面から消して、同じ場所に同じ大きさと色で訳文を描き直します。ページが初めから日本語だったかのように読めて、新しいメッセージが届いても、スクロールしても、訳文がついてきます。

レンズひとつで
• チャットとフィード：新しいメッセージが届くたびに翻訳します。
• ゲームと動画の字幕：模様のある背景や動いている場面の文字も読み取ります。
• 論文とドキュメント：2段組みの論文は段ごとにその場で翻訳し、コードと数式は原文のままにします。
• 画像：画像ファイルをドラッグ＆ドロップするか貼り付けると（「画像を翻訳…」）、同じように翻訳します。

使い方
• ⌃⌥Lを押して、読みたいところにドラッグで枠を描くと、レンズができます。レンズの内側はクリックが通り抜けるので、いつもどおりスクロールしたり会話したりできます。
• ⌃⌥Oで原文と訳文を切り替えます（「元のテキストを表示」）。
• ウインドウのレンズはそのウインドウに追従し、画面のレンズは置いた場所の下にあるものを何でも翻訳します。
• レンズのメニューから、「原文をコピー」「翻訳をコピー」「読み上げ」「レンズの画像を保存」を選べます。
• レンズはキーボードでも置けて、VoiceOverで読み上げられます。「視差効果を減らす」をオンにすると、動きが止まります。

プライバシー
Apple翻訳を使ってMacの中で翻訳し、画面の内容がどこかに送られることはありません。分析ツールもありません。OllamaやLM StudioなどこのMac上の翻訳サーバを使うこともできます。

動作環境
• macOS 26以降、Apple silicon（M1以降）
• 「画面収録」の許可（レンズの下の文字を読み取るために使います。録画や保存はしません）
• 言語パックがあれば、翻訳はほぼ一瞬で、オフラインでも使えます。
