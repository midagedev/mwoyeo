**Name** (15): `Mwoyeo – 实时屏幕翻译`

**Subtitle** (13): `屏幕上的外文，实时就地翻译`

**Promotional text** (78):
画面一变，译文跟着变。新的聊天消息、切换的字幕、滚动的页面，透镜都会持续读取，并在原处以相同的大小和颜色重写译文。默认设置下，所有处理都在 Mac 上完成。

**Keywords**: `OCR,翻译器,即时,游戏,字幕,聊天,论文,日语,韩语,英语,悬浮,取词,外语`

**Description**:
屏幕上的外文，就在原处实时翻译。

新的聊天消息、切换的字幕、滚动的页面：译文会一直跟上屏幕。

没有弹窗，也没有字幕条。Mwoyeo 会读取透镜下方的文字，把它从屏幕上擦掉，再在同一位置以相同的大小和颜色写上译文。读起来就像页面本来就是你的语言，新消息到来或滚动页面时，译文也会跟上。

一个透镜，应对各种场景
• 聊天和信息流：新消息一到就翻译。
• 游戏和视频字幕：花纹背景和移动画面上的文字也能读取。
• 论文和文档：双栏论文逐栏就地翻译，代码和公式保持原样。
• 图像：拖入或粘贴图像文件（“翻译图像…”），同样就地翻译。

使用方法
• 按下 ⌃⌥L，在想读的地方拖出一个框，透镜就出现了。透镜内部不拦截点按，所以你照常滚动、聊天。
• 按 ⌃⌥O 在原文和译文之间切换（“显示原文”）。
• 窗口透镜会跟随它所在的窗口；屏幕透镜留在原位，翻译下方的一切。
• 在透镜菜单中，可以选“拷贝原文”“拷贝译文”“朗读”或“存储透镜图像”。
• 可以用键盘放置透镜，VoiceOver 也能读出它。开启“减弱动态效果”后，透镜会保持静止。

隐私
默认情况下，Mwoyeo 使用 Apple 翻译，所有处理都在你的 Mac 上完成，屏幕上的任何内容都不会发送到别处。没有任何分析工具。你可以添加这台 Mac 上的引擎，例如 Ollama 或 LM Studio，也可以添加使用你自己密钥的云端引擎。云端引擎在首次发送任何内容前，会按引擎和主机各询问一次许可，而且只发送透镜读取的文字，绝不发送屏幕图像。密钥只存储在 macOS 钥匙串中。

系统要求
• macOS 26 或更高版本，Apple 芯片（M1 或更新）
• “录屏”权限（用于读取透镜下方的文字，不会录制或保存任何内容）
• 安装语言包后，翻译几乎瞬间完成，离线也能使用。
