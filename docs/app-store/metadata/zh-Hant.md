**Name** (15): `Mwoyeo – 螢幕就地翻譯`

**Subtitle** (13): `透鏡一罩，外文變成你的語言`

**Promotional text** (75):

**Keywords**: `OCR,翻譯器,即時,遊戲,字幕,聊天,論文,日文,韓文,英文,懸浮,取詞`

**Description**:
螢幕上的外文，就地變成你的語言。

沒有彈出視窗，也沒有字幕列。Mwoyeo 會讀取透鏡下方的文字，把它從螢幕上擦掉，再在同一位置以相同的大小和顏色寫上譯文。讀起來就像頁面本來就是你的語言，新訊息到來或捲動頁面時，譯文也會跟上。

一個透鏡，應對各種場景
• 聊天和動態消息：新訊息一到就翻譯。
• 遊戲和影片字幕：花紋背景和移動畫面上的文字也能讀取。
• 論文和文件：雙欄論文逐欄就地翻譯，程式碼和公式保持原樣。
• 影像：拖入或貼上影像檔案（「翻譯影像…」），同樣就地翻譯。

使用方法
• 按下 ⌃⌥L，在想讀的地方拖移出一個框，透鏡就出現了。透鏡內部不攔截點按，所以你照常捲動、聊天。
• 按 ⌃⌥O 在原文和譯文之間切換（「顯示原文」）。
• 視窗透鏡會跟隨它所在的視窗；螢幕透鏡留在原位，翻譯下方的一切。
• 在透鏡選單中，可以選「拷貝原文」「拷貝譯文」「朗讀」或「儲存透鏡影像」。
• 可以用鍵盤放置透鏡，VoiceOver 也能讀出它。開啟「減少動態效果」後，透鏡會保持靜止。

隱私
預設情況下，Mwoyeo 使用 Apple 翻譯，所有處理都在你的 Mac 上完成，螢幕上的任何內容都不會傳送到別處。沒有任何分析工具。你可以加入這部 Mac 上的引擎，例如 Ollama 或 LM Studio，也可以加入使用你自己金鑰的雲端引擎。雲端引擎在首次傳送任何內容前，會依引擎和主機各詢問一次許可，而且只傳送透鏡讀取的文字，絕不傳送螢幕影像。金鑰只儲存在 macOS 鑰匙圈中。

系統需求
• macOS 26 或更新版本，Apple 晶片（M1 或更新）
• 「螢幕錄影」權限（用於讀取透鏡下方的文字，不會錄製或儲存任何內容）
• 安裝語言包後，翻譯幾乎瞬間完成，離線也能使用。
