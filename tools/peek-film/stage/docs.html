Starting a session

A session keeps the state of one conversation between requests. Create it once, then pass its id with every message you send.

// open a session and send a message
let session = try await client.open()
try await session.send("Hello")
for try await reply in session.replies {
    print(reply.text)
}
FieldMeaning
idUnique id of the session
expiresTime when it closes if idle
regionWhere its data is stored
