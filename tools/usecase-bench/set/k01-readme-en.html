ledgerline: a small ledger for the terminal

ledgerline reads plain text journals and prints the balance of every account. It needs no database and no account on a server.

Installation

Install the latest release with Homebrew and check the version.

$ brew install ledgerline
$ ledgerline --version
ledgerline 0.4.2
Usage

Run it with --month 2026-09 to see one month only. Settings live in ~/.ledgerrc.

# ~/.ledgerrc
currency = "EUR"
round_to = 2
