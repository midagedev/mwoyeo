How do I flatten a nested array in JavaScript?
Asked 5 months ago　　Viewed 18k times
Answer

Since ES2019 you can call Array.prototype.flat(). Pass a depth when the nesting is deeper than one level.

const nested = [1, [2, [3, [4]]]];
// flatten every level at once
const flat = nested.flat(Infinity);
console.log(flat); // [1, 2, 3, 4]

On an older runtime, install a polyfill first.

$ npm install core-js

Avoid concat here, because it only removes one level.
