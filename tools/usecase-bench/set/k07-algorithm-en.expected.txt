Algorithm 1 groups the recognized lines greedily. A line joins the previous group when its vertical gap d is below τ times its height; otherwise it opens a new group. (inline: d ; τ)
Algorithm 1 Greedy paragraph grouping
Input: ℓ1, …, ℓn; τ (keep:math)
Output: G (keep:math)
G ← [[ℓ1]] (keep:math)
for i ← 2 to n do (keep)
d ← top(ℓi) − bottom(ℓi−1) ▷ vertical gap (keep)
if d < τ · height(ℓi) then (keep)
append ℓi to the last group of G (keep)
else (keep)
open a new group with ℓi (keep)
end if (keep)
end for (keep)
return G (keep)
The loop runs once over the lines, so the time is linear in n. (inline: n)
