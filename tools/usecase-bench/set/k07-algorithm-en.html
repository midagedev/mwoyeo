Algorithm 1 groups the recognized lines greedily. A line joins the previous group when its vertical gap d is below τ times its height; otherwise it opens a new group.

Algorithm 1 Greedy paragraph grouping
Input: ℓ1, …, ℓn; τ
Output: G
1:G ← [[ℓ1]]
2:for i ← 2 to n do
3:    d ← top(ℓi) − bottom(ℓi−1)   ▷ vertical gap
4:    if d < τ · height(ℓi) then
5:        append ℓi to the last group of G
6:    else
7:        open a new group with ℓi
8:    end if
9:end for
10:return G

The loop runs once over the lines, so the time is linear in n.
