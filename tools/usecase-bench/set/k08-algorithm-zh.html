算法 1 在有序数组中查找目标值。每一轮把搜索区间缩小一半，因此耗时与 n 的对数成正比。

算法 1 二分查找
Input: A[1..n]; x
Output: i
1:lo ← 1, hi ← n
2:while lo ≤ hi do
3:    mid ← ⌊(lo + hi) / 2⌋   ▷ 取中点
4:    if A[mid] = x then return mid
5:    else if A[mid] < x then lo ← mid + 1
6:    else hi ← mid − 1
7:end while
8:return 0   ▷ 未找到

当数组中没有目标值时，算法返回 0。
